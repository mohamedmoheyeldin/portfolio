# Design brief: the poster

The site is set as a typographic poster: the name is the image, every project opens on one verb at poster scale, and blue is a ground, not only an accent. The full Scrollcraft brief (grammar, journey, feeling curve, score, signature move and fingerprint gate) is in [SCROLLCRAFT-BRIEF.md](SCROLLCRAFT-BRIEF.md).

- **Two themes, designed separately.** Light: a white ground, a cool grey band, near-black ink and a cobalt plate (blue-700). Dark: a blue-black ground, a raised navy-grey band, slightly heavier and wider-tracked type, raised result panels with an edge highlight, and a deep navy plate. Both are built from the upstream Untitled UI tokens; blue is the only hue. The plate re-themes the components inside it through the same semantic tokens, so buttons on it stay Untitled UI buttons.
- **Type.** Archivo (display: the wordmark, project verbs, headings, results; its width axis runs from 68% for poster lines to 92% for the claim) and Inter (text and interface). Two families. Display lines are uppercase only at poster scale (the name, the verbs, "Email me"); tracking tightens as size grows.
- **Structure over cards.** Hairlines, alignment and hard changes of ground do the grouping. The only panels are the project results (a real object: the claim and where its evidence comes from) and the credential badges.
- **Evidence first.** Each project: verb, context, name, what I did, the result with its evidence source (user-reported, public source, documented responsibility, derived from the record), problem, role, then decisions and evidence in a disclosure, the tools, and the links.
- **The trace.** Any tool name traces itself through the work: the projects and roles that used it light up, the rest dim, and a bar lists them. Without JavaScript the stack links each tool to its projects.
- **Motion.** Native CSS only, behind `prefers-reduced-motion: no-preference` and `@supports (animation-timeline: view())`. The resting state is the visible state. No scroll-jacking, no pinning, no scroll cues, no section numbers.
- **Content rules.** Career facts come from `career.json`; no invented numbers, logos, generated imagery or mock interfaces. The one figure (the Claims Document Assistant pipeline) is an ordered list restating the project description. Project verbs restate the first clause of each description.
- Existing resume documents keep their own layout. The web redesign does not change the PDF or Word output.
