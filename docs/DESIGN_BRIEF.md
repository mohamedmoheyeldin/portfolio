# Design brief — Untitled UI redesign

- Light surfaces, blue accents, Inter loaded as in the official Untitled UI Vite starter, readable type, and generous spacing.
- Use free Untitled UI components throughout reusable UI: navigation, actions, filters, inputs, badges, icon tiles, and empty states. Compose content layouts with its theme tokens; use a simple name link and omit decorative artwork. No PRO components or separate component catalog.
- Lead with Mohamed's engineering work. Feature this website as an independent project with a public source link and an explanation of its architecture.
- Use original architecture and interface illustrations. Do not show simulated test results as real project metrics.
- Preserve career facts, case-study URLs, contact links, PDF/DOCX downloads, metadata, and subpath portability.
- Keep the main content usable without JavaScript. Hydrate the work explorer for search and filters.
- Respect reduced motion and validate mobile layouts, keyboard behavior, and contrast.
- Existing resume documents retain their current layout. The web redesign does not imply regenerated PDF or Word documents.
